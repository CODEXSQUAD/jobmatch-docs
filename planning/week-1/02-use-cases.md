# Описать пользовательские сценарии и права доступа MVP

- **Репозиторий Issue:** `jobmatch-docs`
- **Ответственный:** Альберт
- **Срок:** День 2
- **Проверяет:** Матвей и Клим

## Описание

Описать поведение приложения с точки зрения пользователей. Сценарии будут основой разработки и приёмки.

## Что сделать

- Создать requirements/use-cases.md для принятых UC-01–UC-10.
- Для каждого сценария указать участника, предварительные условия, шаги и итог.
- Описать основные ошибки: нулевой лимит, повторный отклик, закрытая вакансия, незаполненное резюме, чужой ресурс.
- Создать requirements/permissions.md с действиями гостя, соискателя и работодателя.
- Согласовать статусы и переходы с правилами MVP.

## Критерии готовности

- [ ] Все сценарии утверждённого MVP описаны.
- [ ] Для каждого сценария есть проверяемый результат.
- [ ] Права и основные отрицательные случаи указаны.
- [ ] Нет противоречий с MVP.
