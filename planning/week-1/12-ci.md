# Настроить автоматическую проверку сборки frontend и backend

- **Репозиторий Issue:** `jobmatch-backend`
- **Ответственный:** Игорь
- **Срок:** День 5
- **Проверяет:** Клим

## Описание

Добавить отдельный GitHub Actions workflow в каждый кодовый репозиторий. Основная Issue находится в backend; связать с ней оба PR.

## Что сделать

- Создать .github/workflows/build.yml в frontend и backend.
- Запускать проверки на PR в main и обновление main.
- В frontend установить зависимости по lock-файлу и выполнить сборку.
- В backend восстановить зависимости и собрать solution.
- Использовать согласованные версии Node.js и .NET.
- Включить существующие содержательные тесты, если они появились; наличие тестов не является условием создания каркаса.
- Описать проверки и просмотр результата в README.

## Критерии готовности

- [ ] Workflow существует в обоих репозиториях.
- [ ] Проверки запускаются на PR.
- [ ] Текущие версии проходят сборку.
- [ ] Проверки не зависят от персональных секретов.
- [ ] Команда знает, где увидеть ошибку.
- [ ] Оба связанных PR приняты.
