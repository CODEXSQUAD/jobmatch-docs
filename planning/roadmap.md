## Правила доски

Используются четыре состояния:

- `Todo` — задача описана, зависимости или работа ещё не начаты;
- `In Progress` — назначен исполнитель и есть фактическая работа;
- `Review` — результат опубликован в PR, назначен проверяющий;
- `Done` — критерии выполнены, ревью пройдено, PR слит или документирован проверяемый результат.

У каждой карточки должны быть исполнитель, дата, репозиторий результата и ссылки на зависимости. Исполнитель обновляет статус при начале работы и открытии PR. Проверяющий переводит задачу в `Done` только после проверки. Блокер фиксируется комментарием с владельцем следующего действия и датой повторной проверки.

## Порядок интеграции

`MVP → сценарии/права → ERD → OpenAPI → backend и frontend → PostgreSQL → каталог → Compose → демонстрация`.

Работы могут идти параллельно, но изменения API и схемы считаются согласованными только после синхронизации документов и кода. Полные критерии продукта находятся в [MVP](../requirements/mvp.md), описания задач — в [плане первой недели](week-1/README.md).
