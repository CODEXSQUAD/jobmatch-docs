# Roadmap учебного MVP

Черновик для первого созвона. Сроки: вторая лабораторная через неделю, третья через три недели от начала планирования. Конкретные даты и доступное время команды нужно подтвердить.

| Период | Работа | Проверяемый результат |
|---|---|---|
| Неделя 1 | Требования, ERD, API-контракты, первичные макеты, каркасы и окружение | React обращается к API, API подключён к PostgreSQL; есть инструкция, доска и план |
| Неделя 2 | Вход, роли, резюме, компания, вакансии и каталог | Кандидат сохраняет резюме, работодатель публикует вакансию, кандидат находит её |
| Неделя 3 | Отклики, лимиты, кабинеты, статусы, проверки и документация | Главный сценарий работает целиком, все согласованные UC выполнены, чистый запуск проверен |
| После лабораторных | Публичное размещение, почта, восстановление доступа, резервные копии | Сайт доступен по HTTPS, данные можно восстановить |
| Далее | Платежи и реклама | Дополнительные отклики начисляются только по проверенным подтверждениям |

Последние два дня перед третьей лабораторной оставить для исправлений и репетиции. Главный сценарий: публикация → поиск → отклик → одно списание → решение работодателя → статус у кандидата.

Полные критерии: [MVP](../requirements/mvp.md).
