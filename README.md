# JobMatch — Документация

JobMatch — сервис поиска работы с ограниченным количеством откликов. MVP проверяет путь от публикации вакансии до решения работодателя; покупка откликов и рекламные награды запланированы после учебного MVP.

## Статус

Документы — предложения для первого созвона. Сценарии, бизнес-правила и стек ещё требуют утверждения командой и согласования с преподавателем. ERD, OpenAPI и макеты пока не подготовлены.

## Ответственность

Матвей ведёт требования и план; Альберт — сценарии и контракты; Влад — дизайн; Клим — архитектуру. Игорь дополняет решения по окружению. Каждый участник сохраняет свой вклад под собственным авторством.
